# PHASE 47 DISCOVERY REPORT: RESEARCH REPRODUCTION & INDEPENDENT VERIFICATION ENGINE

## 1. Existing Phase 46 Manifest Architecture
Phase 46 tracks explicit dataset identities, parameters, and methodology hashes in a `ResearchReproducibilityManifest`. It flags when reproducibility *is expected* to fail (e.g. `DATA_CHANGED`), but does not actually reconstruct the research.

## 2. Existing Research Specification Representations
`FrozenSpecification` logic exists in Phase 18, and `ResearchCandidateSnapshot` exists in Phase 21. `ResearchCodeProposal` exists in Phase 27. These are passive tracking schemas or sandbox runners. They lack a unified `FrozenResearchSpecification` wrapper binding explicit original metric outputs against dynamically reproduced equivalents.

## 3. Existing Experiment Execution Boundaries
Phase 27 handles execution of AI proposals within the `ASTSecurityValidator` and isolated sandbox. Any active reproduction of methodology requiring execution must route through this bounded execution box to prevent arbitrary `os.system` / subprocess vulnerabilities.

## 4. Existing Numerical Metrics
PnL, Trade Count, and Risk Metrics exist across Phase 19 (`PaperTrackRecord`), Phase 42 (`PortfolioIntelligence`), etc.

## 5. What can safely be reproduced
Deterministic mathematical projections, exact parameter-to-metric mappings for static datasets, structural sequencing (number of trades generated by a frozen signal over frozen data).

## 6. What cannot safely be reproduced
Live external API fetching, real-time unpersisted orderbook sequences, or non-deterministic ML convergence without hard-seeded weights.

## 7. Exactly what Phase 47 adds
Phase 47 bridges the gap from *Governance Tracking* (Phase 46) to *Active Verification*. It pulls the `ResearchReproducibilityManifest`, forms a `FrozenResearchSpecification`, passes it to a bounded `runner.py`, extracts a canonical `ReproducedResearchOutput`, and runs `numerical/structural comparisons` against the `OriginalResearchOutput`. Discrepancies generate a definitive `ReproductionStatus` distinguishing between exact matches, tolerance matches, structural differences, or regressions.
