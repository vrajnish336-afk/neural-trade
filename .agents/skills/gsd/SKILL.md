# Get Shit Done (GSD) Workflow

Use this workflow to tackle complex tasks methodically.

## Phases

1. **Discovery & Planning**
   - Analyze the current state of the codebase.
   - Identify affected components.
   - Write a clear plan of action (can be output as an Artifact).
   - Get user approval if the changes are structural.

2. **Execution**
   - Break down the plan into small, manageable steps.
   - Execute one step at a time.
   - Commit to the Ralph Loop for each step (Implement -> Test -> Fix).

3. **Verification**
   - Ensure all acceptance criteria are met.
   - Verify there are no regressions in existing functionality.

4. **Wrap-up**
   - Present a summary of what was accomplished.
   - Propose the next logical step.
