# Workspace Rules for Neural Trade

## Development Workflow
1. **Ralph Loop**: For all coding tasks, you MUST strictly adhere to the Ralph Loop:
   - PLAN: Understand the requirements and outline changes.
   - IMPLEMENT: Write the code.
   - TEST: Run the test suite (`pytest`).
   - INSPECT FAILURE: If tests fail, analyze the output.
   - FIX: Correct the code.
   - TEST AGAIN: Re-run tests until they pass.
   - REVIEW: Run the local code-review skill.
   - REPEAT: Stop only when acceptance criteria are met or human input is needed.
2. **Get Shit Done (GSD)**: Use the `gsd` skill for structured planning and phased execution for large features.
3. **Code Review**: Treat the `code-review` skill as our CodeRabbit equivalent. Always review code before completing a task.
